# 📞 CET303 VoIP Implementation Project

## 📖 Overview

This project demonstrates the practical implementation of a VoIP PBX environment using **FreePBX** and **Asterisk** technologies within a **Debian 12 virtual machine**.

The project focused on designing and implementing a functional VoIP PBX environment capable of supporting geographically distributed business communication through SIP-based VoIP technologies.

---

# 🚀 Core Features

✅ SIP Extension Configuration  
✅ Voicemail Integration  
✅ IVR / Auto-Attendant System  
✅ Ring Group Configuration  
✅ Audio Conferencing Rooms  
✅ Call Blocking / Blacklisting  
✅ VoIP Security Configuration  
✅ VoIP Traffic Capture
✅ FreePBX Firewall Protection  
✅ Music on Hold (MOH)
